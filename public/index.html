What does this test?

A real Phonon voice embedding is loaded into Blixt’s runtime and used to generate 24 kHz audio. Uploaded files never leave your browser. English model: Apache 2.0.

Creating a voice from a WAV is a separate, cloud-based step using Gradium’s cloning script. This demo loads an existing voice file; it does not clone recordings.
